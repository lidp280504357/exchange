# 前端人工检查清单

依据：设计文档 `docs/设计-体验重构与市场钱包扩展-2026-09-30.md` §12.3。每批前端（B2 PC 站、B3 手机站、B5 后台）验收前逐项勾选，结果与日期写进设计文档 §11.1 的验收记录。工具能测的（性能预算、硬编码颜色、类型、单元测试、e2e）不在这里，见 [web.md](web.md)。

2026-10-04 起，本清单能稳定自动判断的部分由浏览器流程逐项检查：`scripts/e2e/webflows.sh [pc] [m] [admin]`（步骤名就是下表的编号，见 [web.md](web.md) 的「检查清单流程」）；每项由哪个脚本的哪一步覆盖、哪些部分仍要人看，见 [阶段4验收报告 §8.1](../阶段4验收报告.md)。人工只需看流程覆盖不到的部分：真机（M6，以及 M5 在 iOS 上真的读取验证码）、动效与手感（M2 弹簧是否流畅、整体观感）、渐变或图片上的文字（3）、K 线与仓位盈亏的配色观感（4）。

## 通用（每个站点都查）

| # | 检查项 | 怎么查 |
|---|---|---|
| 1 | 导航每一项可达，没有死链 | 顶栏、页脚、下拉菜单逐个点开；未登录点需要登录的页面应跳到登录并能回来 |
| 2 | 无横向滚动 | PC：1024 / 1280 / 1920 宽；手机：360 / 390 / 430 宽；每页滚到底 |
| 3 | 深浅色对比度 ≥ 4.5:1 | Chrome DevTools 的 CSS Overview 或 Lighthouse 无障碍项；重点看次要文字 `text-fg-3` 与禁用态 |
| 4 | 涨跌色切换全站生效 | 设置里切"红涨绿跌"，看行情、终端、资产、K 线、盘口、成交、仓位盈亏 |
| 5 | 减少动效偏好生效 | 系统打开"减少动态效果"，页面切换、列表入场、价格闪动、抽屉都应退化为无动画 |
| 6 | 断网提示与自动恢复 | DevTools 设为 Offline：顶部出现"网络不可用"；恢复后横幅消失，行情继续更新，无需刷新 |
| 7 | 令牌过期自动续期不打断操作 | 登录后等访问令牌过期（或在 DevTools 删掉内存外的状态后操作）：请求自动续期，表单内容不丢 |
| 8 | 表单错误就地显示 | 每个表单故意填错：错误出现在对应字段下，服务端错误码映射到字段 |
| 9 | 空态有引导 | 新注册账户看委托、成交、资金流水、通知、仓位：都有插画、说明和下一步按钮 |
| 10 | 长文本截断有 tooltip | 长邮箱、长地址、长交易哈希、长币种名：截断处悬停可见全文或可复制 |
| 11 | 时间与时区一致 | 设置里换时区：K 线、表格、详情里的时间同时变化，格式一致（YYYY-MM-DD HH:mm:ss） |
| 12 | 数字对齐 | 价格、数量、金额列右对齐且等宽（`tabular-nums`），精度与交易对/资产一致，千分位正确 |

## PC 站（astras.vip）

| # | 检查项 |
|---|---|
| P1 | 键盘可完成登录：Tab 顺序合理、焦点可见、Enter 提交、验证码框自动聚焦 |
| P2 | 键盘可完成下单：`/` 打开交易对搜索，方向键选择，`B` / `S` 切买卖，Enter 提交，`Esc` 关闭弹层 |
| P3 | ⌘K / Ctrl+K 打开全站搜索，可跳到现货或合约终端 |
| P4 | 终端：盘口点击价格填入下单价，Shift+点击同时填入累计数量；切换交易对不重连、不闪白 |
| P5 | 终端：拖动委托面板分隔条改变高度，刷新后保持；深度图折叠状态、K 线周期、指标、盘口精度刷新后保持 |
| P6 | 下单确认弹窗可在设置里关闭；余额不足的错误带"充值"入口 |
| P7 | 合约：降级（只减仓）时顶部黄色横幅；资金费倒计时每秒更新；杠杆 > 20 有风险提示 |
| P8 | 页脚"切换到手机版"后，本机访问 PC 站不再被分流到手机站 |

## 手机站（m.astras.vip，B3 填写）

| # | 检查项 |
|---|---|
| M1 | 所有点击目标 ≥ 44 px；底部 tab 栏不被系统手势条遮挡（安全区） |
| M2 | 抽屉（下单、交易对切换、筛选、step-up）可下拉关闭；弹簧动画流畅 |
| M3 | 列表下拉刷新；终端图表/盘口 tab 左右滑动切换 |
| M4 | PWA 可安装到主屏；离线时显示"网络不可用"页 |
| M5 | 验证码输入框在 iOS 上能自动读取短信/邮件验证码（`autocomplete="one-time-code"`） |
| M6 | 真机验证：iOS Safari 与 Android Chrome 各走一遍注册、下单、划转 |

## 管理后台（admin.astras.vip，B5 填写）

| # | 检查项 |
|---|---|
| A1 | 每个列表分页、筛选、排序可用，刷新后筛选保留在 URL |
| A2 | 危险操作（冻结、撤单、调账、开关、提现审批、合约状态）全部有确认，需要填写原因 |
| A3 | 无权限的操作按钮隐藏或禁用，并说明需要的权限 |
