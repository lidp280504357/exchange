## 3. 工作项覆盖（实施计划 §7.1）

| 工作项 | 实现 |
|---|---|
| 合约账户隔离、逐仓/全仓、单向/双向、杠杆档位、风险限额阶梯、保证金追加/减少 | 用户 `FUTURES` 账户（USDT）与现货隔离，转入转出走 `ACCOUNT_TRANSFER`；按合约设置持仓模式（无仓位无挂单时可切换）、保证金模式与杠杆（有仓位时按阶梯重新校验，全仓仓位的保证金随杠杆调整）；逐仓追加/减少保证金 |
| 指数价、标记价、溢价指数、资金费率、预估强平价 | §11.7 公式逐条实现并有单元测试：指数价 = 加权中位数、剔除偏离 > 3% 的价源、最少价源数（测试服 1，只有币安）；标记价 = 指数 × (1 + 基差 30 秒 EMA)，限制 ±1%；溢价按冲击名义价值取盘口；资金费率 = clamp(P + clamp(I − P, ±0.05%), ±上限)；逐仓预估强平价 |
| 开仓、平仓、只减仓、止盈止损、仓位事件、盈亏；撮合复用 | 限价、市价（保护价 IOC）、只减仓；成交按"每手预留"（保证金与手续费按手冻结）结算，订单与成交事件的先后无关；开、加、减、平、反手；按标记价或最新价触发的止盈止损；撮合复用现货引擎代码，单独分片 |
| 强平预警、撤单、接管、限价平仓、保险基金、ADL、穿仓保护、异常价格 | 维持保证金 1.2 倍预警、1.3 倍解除；到维持保证金接管、撤该仓位挂单；逐仓按破产价、全仓按标记价 ± 0.5% 下 IOC 强平单；亏损最多到保证金为止，不足由保险基金付，优于破产价的剩余进保险基金；3 次不成交按盈利 × 有效杠杆排名 ADL；价格带、标记价 ±1% 钳位、指数剔除异常价源 |
| 故障时 `REDUCE_ONLY`、人工恢复 | 见 §2 第 3 条 |
| 模拟盘、历史重放、压力测试、资金费率与强平对账、H5/PC 页面 | 只用模拟资金（开关 `derivatives.trading` 默认关闭）；读模型可由事件回填、引擎由快照与 WAL 重放；资金费与强平对账见 §2 第 2 条；H5 合约页即 PC 与手机共用的网站。**压力测试未做**（用户 2026-09-29 决定测试服暂不压测） |

## 5. 故障场景覆盖

| 场景 | 方式 | 预期 |
|---|---|---|
| 价源中断 / 标记价不可用 | `contract-degrade.sh`；应用层测试 | 下单报 `DERIV_MARK_PRICE_UNAVAILABLE`，10 秒后只减仓；恢复后仍只减仓（`DERIV_REDUCE_ONLY_MODE`），人工解除后恢复 |
| 账本不可用或拒绝结算 | 应用层测试 `TestRefusedSettlementsWaitForTheLedger` | 结算停放在 `pending_settlements`，按幂等键重试，停放期间对账报 `NO_PENDING_SETTLEMENTS` |
| 保险基金不足 | 账本集成测试 | 结算失败并停放，注资后自动重试 |
| 强平单无法成交 | `TestAnUnfillableLiquidationIsDeleveraged` | 3 次后 ADL，对手方按破产价被减仓 |
| 资金费率迟到或缺失 | 资金费测试 | 结算时刻快照仓位，费率到后结算；2 小时无费率则跳过；`exchangectl derivatives funding` 检查卡住的轮次 |
| 合约撮合分片崩溃 | 复用现货引擎的主备与 WAL（`matching-failover.sh` 验证过现货分片） | 同现货；合约分片未单独演练 |

## 7. 已知限制与遗留

| 项 | 说明 | 去向 |
|---|---|---|
| 资金费的端到端 | `funding.sh` 第一次运行只开常驻对冲仓位，资金费结算要等下一个资金费时间点后再跑一次才核对到 | §8 第 5 步 |
| 合约做市 | 已按 §11.10 实现（同一 market-maker 以标记价为中心报价，库存按净仓位 ±0.5 限制），测试服只给 BTC-USDT-PERP 配置；做市不对冲，ETH-USDT-PERP 没有做市；"无足够流动性不得开放开仓"由运维控制，代码不强制 | 需要时给更多合约配置做市 |
| 指数价源 | 外部只接币安，测试服最少价源数配成 1；多源中位数的逻辑有测试但只有一个真实价源 | 上线前检查项 |
| 强平端到端 | 强平依赖真实价格波动，端到端脚本无法稳定触发；由应用层场景覆盖（上真实库后同样覆盖 SQL） | 需要时手工演练：高杠杆逐仓小仓位等行情波动 |
| 风险服务故障降级 | 合约服务不同步依赖 risk-service，这一条不适用 | — |
| 压力测试 | 合约下单与撮合没有压测 | 用户决定暂不压测 |
| 交割合约、多资产保证金、组合保证金 | 不在阶段 3 范围 | 阶段 4 |
