## 3. 关键决策速查（详见评审 §8 与 ADR）

- 单仓库单 module；chi、pgx、goose、franz-go、clickhouse-go、go-redis、decimal、golang-jwt、oapi-codegen、slog、OTel、koanf、testcontainers。
- 金额 decimal + NUMERIC(38,18) + JSON 字符串；ID UUIDv7 + int64 序号。
- 密码 + 验证码注册；密码登录；7 天无成功登录追加验证码；JWT Ed25519 15 分钟 + refresh 30 天轮换；H5 refresh 放 HttpOnly cookie。
- 现货：maker/taker 0.10%，买收 base 卖收 quote；做市机器人自营不对冲；提现到站内地址转内部划转。
- 合约：默认参数并支持双向持仓；复用现货撮合引擎分片。
- 链：Sepolia + 自部署测试 ERC-20；Alchemy RPC；signer 独立进程 + 加密 keystore。
- 部署：本机不装 Docker，服务器拉代码构建；观测暂缓；管理后台独立域名 + TOTP + IP 白名单。
- 行情：开发期用 Binance 公共端点，上线前必须换授权源（学习前提下为检查项）。

## 7. 风险提醒

- t2.medium 突发型实例：不作压测基准；应用容器全部上来后内存会紧，届时升配或加应用机。
- 单人开发：ADR 与 runbook 是唯一的"交接文档"，改架构必须先改 ADR。
- 数据库为空库，任何迁移都可以从零设计，不需要兼容历史数据。
