# ADR-0009：密码 + 验证码注册登录，7 天无登录触发二次验证

- 状态：已接受（2026-09-29）
- 关联：需求 §2.1、§5.2、§6；决策 #5、#6、#7、#24

## 背景

初稿为纯验证码登录，用户改为传统密码登录并要求尽量少打扰：只有账户长期未登录才追加验证码。

## 决策

1. 注册：设置密码 + 邮箱或手机验证码验证身份；发送验证码前必须通过 Cloudflare Turnstile。
2. 登录：默认密码登录；账户最近 7 天内无成功登录时，密码通过后追加验证码二次验证；保留验证码登录入口作备用。不做 IP 地理位置判断。
3. 密码：Argon2id，长度 10–128，拒绝弱密码与泄露密码字典，10 次失败锁定 15 分钟，3 次失败后要求人机验证。
4. Token：JWT（Ed25519）access 15 分钟 + 不透明 refresh 30 天轮换并检测重放；H5 的 refresh 放 HttpOnly/SameSite=Strict cookie（限定刷新路径），access 只在内存；Tauri 与移动端用系统安全存储 + 请求体刷新。
5. 敏感操作（提现、换绑、白名单、安全设置）需要 step-up：TOTP 优先，否则另一身份验证码。
6. 引导绑定第二身份；单身份账户提现限额降为 20%；密码重置或换绑后 24 小时内提现人工审批。

## 理由

密码是第一道门，验证码只在风险升高（长期未登录）时介入，兼顾安全与体验；无地理位置判断避免 VPN 用户被频繁打扰。

## 后果

- 需要密码策略、重置流程与弱密码字典维护。
- "7 天"为可配置阈值，写入功能开关/配置表。

## 备选

纯验证码登录（用户否决）；IP 地理位置变化触发（用户否决）。
