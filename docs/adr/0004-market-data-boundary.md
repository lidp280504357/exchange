# ADR-0004：外部行情只作参考与指数输入，上线前必须取得授权

- 状态：已接受（2026-09-29）
- 关联：需求 §5.11、§11.8、§11.9、§11.10；决策 #11

## 背景

Binance 服务条款禁止未经书面同意将其数据用于交易服务与行情分发。本项目为学习项目，但架构上不能把 Binance 数据焊死在交易路径里。

## 决策

1. 交易页 K 线、ticker、深度只来自平台自身成交与订单簿；外部数据以独立 `source` 字段存储与展示，永不与平台数据混算。
2. 指数价由多源（≥3）中位数计算，每个源是一个可单独开关的 Adapter；标记价、强平、做市参考价都只依赖指数价，不直接依赖任何单一供应商。
3. 开发与测试期允许使用 Binance 公共端点；任何面向真实用户的环境上线前，必须完成三选一：取得 Binance 授权、购买有再分发许可的聚合数据、自建合规多源指数。该项列为灰度门禁。
4. 供应商名称、logo 与"数据来源"文案出现在客户端前需法务确认。

## 理由

条款风险是阻断性的；Adapter 化让替换数据源不改领域逻辑。

## 后果

- 阶段 2 需要至少实现两个行情 Adapter（一个真实、一个模拟/回放）以验证可切换。
- 学习前提下该门禁不阻塞开发，但文档与代码注释必须保留提醒。

## 备选

直接分发 Binance 行情（被否决：条款）；只用自有成交数据（被否决：新交易所无成交时指数价无来源）。
